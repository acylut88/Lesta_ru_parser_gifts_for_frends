# 🎁 Lesta.ru Shop & Gift Parser

Автоматизированный модульный парсер премиум-магазина **Lesta.ru** (Мир Танков / Мир Кораблей), написанный на Python с использованием ООП и принципов DRY. Скрипт собирает актуальные товары из всех категорий меню, автоматически скачивает оригинальные изображения, сортирует их по папкам и генерирует красивую, полностью автономную интерактивную веб-витрину с умной фильтрацией.

Проект специально оптимизирован для быстрого поиска предложений, которые **можно подарить другу** (содержит фильтр по индикатору рукопожатия `gift-indicator`).

---

## 🛠️ Функционал
*   **Динамический парсинг**: Сбор вкладок меню и карточек товаров в режиме реального времени через скрытый браузер (Selenium).
*   **Медиа-архиватор**: Автоматическое скачивание картинок товаров и их распределение по подпапкам категорий.
*   **Умная очистка**: Фильтрация дубликатов на лету (благодаря хэшированию уникальных ID товаров).
*   **Полная автономность веб-витрины**: Страница переведена на чистый, встроенный CSS и независимую JS-логику. Она работает **без интернета** и мгновенно загружается в условиях любых сетевых блокировок CDN.
*   **Гибкое управление**: Моментальная фильтрация по вкладкам, поиск подарков, товаров со скидками, быстрая сортировка, а также **живой числовой фильтр диапазона цен (От / До)**.
*   **Прямые ссылки**: Каждая сгенерированная карточка содержит кнопку для быстрого перехода на официальную страницу покупки товара.

## 🚀 Быстрый запуск

### 1. Подготовка окружения
Убедитесь, что вы находитесь в корневой директории проекта, и активируйте ваше виртуальное окружение:

```powershell
# Для Windows PowerShell
.venv\Scripts\activate
```

### 2. Установка зависимостей
Установите библиотеки, необходимые для стабильной работы автоматизации браузера и скачивания картинок:

```bash
pip install selenium webdriver-manager requests
```

### 3. Запуск парсинга и генерации страницы
Запустите единый конвейер через корневую точку входа:

```bash
python main.py
```

После завершения работы в консоли отобразится отчет о количестве собранных товаров, а в папке `parsed_data/` обновится файл `index.html`.

## 💻 Использование веб-витрины

1. Перейдите в папку `parsed_data/`.
2. Откройте файл `index.html` в любом браузере.
3. **Управление интерфейсом:**
    *   Нажимайте на кнопки категорий сверху для быстрого переключения между разделами магазина.
    *   Используйте кнопку **«🤝 Только подарок»** для мгновенной фильтрации предметов, доступных для отправки товарищам.
    *   Используйте кнопку **«🔥 Скидки»**, чтобы увидеть товары с уценкой.
    *   Вводите числа в инпуты **«Диапазон цен (₽): От — До»** для мгновенного отсечения товаров, не проходящих по бюджету.
    *   Сортируйте выдачу по возрастанию или убыванию цены через выпадающий список справа.
